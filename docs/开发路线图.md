# Egangnal 开发路线图

路线图遵循“小步提交、文档先行、每步可验证”的原则。只有当前阶段达到验收标准后，才进入下一阶段。

## 阶段 0：产品与工程基线

状态：已完成（2026-08-03）

目标：固定产品边界、计时语义、存储方向和开发质量要求。

交付物：

- 产品需求文档。
- 本地优先与长期计时架构决策。
- 开发规范和质量门槛。
- 分阶段路线图。
- 项目 README。

验收标准：

- 日语、英语独立累计时长的规则无歧义。
- 后台、重新激活、退出、休眠和单主窗口行为有明确约束。
- 资料导入的复制与只读边界清晰。
- 后续每个阶段都有可验证的完成条件。

## 阶段 1：沉浸式工作台

状态：已完成（2026-08-03）

目标：依据界面草图重建应用外壳，不提前接入计时和资料业务。

建议拆分：

1. 将应用收敛为单主窗口，建立总览、日语空间、英语空间的类型安全导航。
2. 完成总览页的水印、日期、个人信息和语言入口布局。
3. 实现昵称编辑、本地保存和重启恢复；头像保持固定占位符。
4. 完成语言空间的资料空状态和返回路径。
5. 适配窄窗口、深色模式、键盘导航和基础辅助功能。
6. 为关键页面和控件补充稳定的 UI 测试标识。

验收标准：

- 可以从总览分别进入日语和英语空间并可靠返回。
- 水印不响应点击，也不被辅助技术误识别为按钮。
- 两个空间在视觉和导航状态上能够明确区分。
- 昵称修改后可以保存，重启应用后仍保持；保存失败会显示明确反馈。
- `820 × 560` 窗口尺寸下没有遮挡、溢出或不可操作区域。
- 构建、单元测试和核心导航 UI 测试通过。

## 阶段 1.1：总览布局收敛

状态：已完成（2026-08-03）

目标：根据实际使用反馈调整首页的信息层级，并把静态日期升级为可展开的当年月份挂历。

交付范围：

1. 将日语、英语入口移动到水印下方，移除基础语法和学习资料占位卡片。
2. 删除首页跨语言汇总时长，只保留两个语言入口各自的时长展示。
3. 将日期卡片移动到个人信息下方。
4. 日期卡片点击后展开当年月份挂历，支持当年月份切换和折叠恢复。
5. 为月份天数计算、展开交互和最小窗口布局补充测试。

验收标准：

- 两个语言入口在水印下方可见、可点击，原占位卡片和首页汇总时长不再出现。
- 日期折叠态保留完整的当前年月日和星期信息。
- 挂历展开后默认当前月，日期与星期排列正确，并且不能切换到当前年份以外。
- 用户可以明确地将挂历切回日期折叠态。
- `820 × 560` 内容区下，个人信息、挂历和两个语言入口没有遮挡或不可操作区域。

## 阶段 1.2：独立主题系统

状态：已完成（2026-08-04）

目标：建立不跟随系统的浅色、深色主题，并让标题栏完整融入应用页面。

交付范围：

1. 建立主题模式、语义调色板和本地偏好存储。
2. 移除系统模糊面板材质，统一总览和语言空间的颜色来源。
3. 隐藏窗口标题、移除标题栏分隔线并延伸页面背景。
4. 在首页右下角加入主题切换按钮。
5. 补充主题切换、持久化、深浅色启动、窗口控件和挂历布局测试。

验收标准：

- 应用当前主题不随 macOS 系统外观改变。
- 深色主题具有清晰、不模糊的面板和更饱和的功能强调色。
- 浅色主题保持简洁、克制，文字和边界清楚。
- 标题栏与页面之间没有可见分界线。
- 主题切换立即作用于总览及两个语言空间，重启后保持选择。
- `820 × 560` 内容区下主题按钮和现有主要入口均可操作。

设计依据：[独立主题系统](design/独立主题系统.md)

## 阶段 1.3：首页视觉收敛

状态：已完成（2026-08-04）

目标：根据实际使用反馈统一首页几何关系，进一步增强深色主题的空间层次和主题切换反馈。

交付范围：

1. 让语言入口和日期面板共享顶部基线。
2. 将语言入口调整为独立卡片比例，并移除首页累计时长。
3. 为深色背景增加克制的红、蓝边缘环境光。
4. 实现从右下主题按钮向窗口扩展的圆形波纹切换。
5. 为最小窗口、入口比例、时长展示边界和主题切换补充测试。

验收标准：

- 语言入口与日期面板上边缘严格平齐，误差不超过 2 点。
- 首页入口不显示累计学习时长，语言空间内部仍可查看对应时长。
- 深色环境光不影响不透明面板、文字和边界的清晰度。
- 主题波纹从按钮位置开始，以连续软边逐步呈现新主题；减少动态效果或快照失败时可靠退化为直接切换。
- 标题栏随同一波纹改变主题，切换期间首页主要控件位置保持稳定。
- `820 × 560` 内容区下入口、挂历和主题按钮没有遮挡或不可操作区域。

设计依据：[首页视觉收敛](design/首页视觉收敛.md)

## 阶段 1.4：品牌文字动效

状态：已完成（2026-08-04）

目标：将首页品牌水印升级为可探索的品牌文字交互，同时保持首页布局稳定和主题动效互不干扰。

交付范围：

1. 将 `Egangnal` 的八个字母按稳定源索引逆序重排为 `Language`。
2. 为中间 `n -> u` 增加独立旋转和字形过渡。
3. 在 `Language` 稳定后淡入 `For`、`Study`，并支持反向收起。
4. 增加减少动态效果、快速重复点击和主题动效互斥处理。
5. 补充字母映射单元测试、品牌 UI 测试和布局稳定性验收。

验收标准：

- 默认品牌文字为 `Egangnal`，点击后最终显示 `For Language Study`，再次点击恢复原状。
- 重排过程中能看到字母移动和 `n -> u` 独立变化，`For`、`Study` 不提前出现。
- 品牌动效不改变首页其他控件的位置或可用性。
- 品牌动效期间主题按钮不可用，主题波纹期间品牌按钮不可用。
- 辅助功能只暴露一个聚合按钮，并能在减少动态效果下直接切换。

设计依据：[品牌文字动效](design/品牌文字动效.md)

## 阶段 2：单词本数据基础

状态：已完成（2026-08-10）

目标：建立本地单词本的格式协议、结构化存储、严格解析和重复词规则，不在本阶段铺开完整界面。

建议拆分：

1. 固定 Markdown 模板的日期、编码、空行和分隔符协议。
2. 建立主词条、导入批次和按日期出现记录的 SwiftData 模型。
3. 实现空白模板生成与严格 Markdown 解析。
4. 实现导入事务、语言隔离、同日幂等和首次释义优先。
5. 为高频词、日期查询和后续编辑提供仓储接口。
6. 补充解析、去重、日期、语言隔离和持久化测试。

验收标准：

- 模板逐行满足固定协议，且不包含已有词条。
- 错误日期、错误分隔符、空字段和空词条文档会被明确拒绝。
- 同一词同一天只产生一次出现记录，跨两个日期后才成为高频词。
- 重复词保留首次成功写入的中文意思，后续意思不覆盖。
- 日语和英语导入完全隔离，一次导入要么全部提交，要么不留下部分数据。
- 应用重启后主词条、批次和出现日期保持一致。

设计依据：[单词本数据基础](design/单词本数据基础.md)；[ADR-002：本地结构化单词本](architecture/架构决策-002-本地结构化单词本.md)

## 阶段 3：单词本浏览与编辑

状态：进行中（2026-08-10）

目标：在语言空间中完成单词本的导入、模板导出、两种浏览方式和显式编辑闭环。

建议拆分：

1. 增加语言空间内的单词本入口和空状态。
2. 接入系统文件导入、模板导出及错误反馈。
3. 实现默认每页 20 条的只读分页和高频词蓝色标记。
4. 实现按日期倒序的一日一页浏览与滚动。
5. 实现显式编辑模式及“未归档单词”分组。
6. 补充分页边界、键盘操作、辅助功能和 UI 测试。

验收标准：

- 0、1、20、21、40、41 条数据下分页边界正确。
- 日期模式一次只显示一天，日期严格倒序且当天条目可滚动。
- 默认分页模式没有增删改入口；进入编辑模式后操作结果可持久化。
- 手动新增不归入当天，在日期模式显示于独立的“未归档单词”分组。
- 导入或导出取消不会改变已有数据，失败时提供可理解的反馈。

## 阶段 4：长期累计计时

状态：实现完成，待 UI 验收

实现设计：[长期学习计时实现设计](design/长期学习计时实现设计.md)

目标：为每个语言空间实现独立、不可手工修改的累计时长。

建议拆分：

1. 建立语言空间和累计时长本地模型。
2. 实现单一应用级计时控制器及纯状态转换测试。
3. 接入空间进入、切换和离开事件。
4. 接入应用非活跃、重新激活、窗口关闭、休眠和退出事件。
5. 增加周期性检查点，限制异常退出造成的时间损失。
6. 在对应语言空间按小时显示一位小数。

验收标准：

- 日语和英语累计值互相独立。
- 切换空间不会重复计时或丢失已提交时长。
- 后台、关闭或休眠期间不累计。
- 应用切出后暂停，切回且仍停留在语言空间时自动恢复。
- 公开 UI 和业务接口都不能直接改写累计值。
- 正常退出时已提交时长零损失；异常退出只允许丢失上次成功检查点之后的未提交增量。
- 重启应用后已持久化累计值保持一致，关闭期间不补算。

## 阶段 4.1：设置与个性化

状态：已完成（2026-08-17）

设计依据：[设置与个性化实现设计](design/设置与个性化实现设计.md)

目标：建立小而明确的设置页面，接入模板默认导出目录，并为首页卡片和页面背景提供可关闭的个性化效果。

交付范围：

1. 建立应用级设置存储，保存两项个性化开关和默认导出目录安全书签。
2. 新增设置路由及首页右下角入口，进入设置时停止语言计时。
3. 移除首页个人信息卡片，将日历移动到右上角。
4. 将用户提供的日语、英语封面图作为低干扰卡片壁纸，并增大卡片文字。
5. 为全部页面背景增加可关闭的细网格。
6. 默认目录有效时直接导出模板，无效或未设置时回退到系统保存面板。

- 设置页只显示模板导出目录和两项个性化开关。
- 两项开关即时生效并在重启后恢复。
- 安全书签失效不会阻塞模板导出，且不会覆盖默认目录内已有同名文件。
- 首页不显示个人信息卡片，日历位于右上，设置按钮位于主题按钮左侧。
- 两套主题和最小窗口下，卡片文字、网格和设置控件清晰且不重叠。

## 阶段 4.2：单词刷

状态：首版第六轮稳定几何修正完成，自动化与截图复核通过，待用户视觉复验（2026-08-18）

设计依据：[单词刷实现设计](design/单词刷实现设计.md)

目标：从当前语言空间已经导入的词库中抽取单词，通过词义选择和单词拼写形成一次完整、可重试错题的测试闭环。

交付范围：

1. 固定小词库四选一、纯手动词范围和同义多词拼写判定规则。
2. 建立纯领域抽题、组题、判分和错题收敛逻辑，并注入可测试的随机源。
3. 包装现有单词本仓储，提供按语言和文档日期隔离的只读候选数据。
4. 新增语言空间入口、类型安全路由，并接入现有语言学习计时边界。
5. 实现左宽右窄的自适应页面、两种题型、答题反馈和结算界面。
6. 补充领域、数据适配、路由计时、键盘操作和核心 UI 测试。

验收标准：

- 学习空间入口保持两列等尺寸卡片：第一行为“学习资料、单词本”，单词刷位于第二行左侧，只读取并累计当前语言空间的数据与时长。
- 默认范围和指定文档日期均可无重复随机抽取最多 20 个词条。
- 简单模式生成 `x` 道词义选择题；深度模式先完成 `x` 道词义选择题，再完成 `x` 道单词拼写题。
- 四选一的正确答案唯一、干扰词义不重复，题目不会因视图刷新或窗口变化而重新随机。
- 全对、存在错题、连续再战错题和返回清空答题区均能完整闭环。
- 测试会话和错题只保存在内存，不新增答题历史或数据库模型。
- 默认窗口和 `820 × 560` 最小窗口下，答题区、有限长分隔线和设置区整体双向居中且不遮挡。
- 单词刷入口在默认和最小窗口下都固定处于“学习资料”正下方，且不横向铺满页面。
- 作答后控件位置保持稳定，答对停留 `1.5` 秒、答错停留 `3` 秒后自动推进。

## 阶段 4.3：单词刷视听反馈

状态：首版完成，单元测试、相关 UI 流程与截图复核通过（2026-08-18）

设计依据：[单词刷实现设计](design/单词刷实现设计.md)

目标：为词义选择题补充克制且不干扰答题节奏的正确反馈动画和可关闭点击音效。

交付范围：

1. 用户直接点中正确选项时，从按钮左上边界开始顺时针绘制一圈绿色细进度线。
2. 环形进度在 `0.4` 秒内完成，不改变现有 `1.5` 秒正确反馈和 `3` 秒错误反馈时长。
3. 将两份用户提供的音频打包为应用资源，词义选项有效点击时播放当前设置的音效。
4. 设置页新增“关闭、音效 1、音效 2”三选一偏好和试听入口，首次启动默认关闭。
5. 补充偏好持久化、动画时序、资源映射和失败降级测试。

验收标准：

- 答对时进度线从圆角矩形左上方沿边界顺时针行进，`0.4` 秒完成且不引起按钮或页面位移。
- 答错时不播放环形进度，已有错误选项和正确答案反馈保持不变。
- 音效在判题结果出现前后均不阻塞界面，也不改变自动跳题状态。
- 关闭音效后不创建播放行为；资源缺失或播放失败时答题仍可正常继续。
- 设置重启后恢复，英语与日语单词刷共享同一选择。
