## 1. 目标与范围

本阶段新增一个独立设置页面，为当前应用提供少量、明确且可本地保存的偏好，同时优化首页信息布局。

本阶段包含：

- 设置单词本 Markdown 模板的默认导出文件夹。
- 开关首页语言卡片封面图。
- 开关全局页面细网格背景。
- 选择或关闭单词刷词义选项点击音效。
- 在首页右下角、主题按钮左侧增加设置入口。
- 移除首页个人信息卡片，将日历固定到首页右上角。

本阶段不包含：

- 头像、昵称或账号设置。
- 主题模式扩展、字体或网格参数自定义。
- 为不同语言设置不同导出目录。
- 云端同步或设置导入、导出。

## 2. 设置状态与持久化

新增应用级 `AppSettingsStore`，由 `AppDependencies` 创建单一实例并注入根视图。设置使用 `UserDefaults` 保存，不进入 SwiftData：这些数据是界面和文件操作偏好，不属于结构化学习内容。

设置项如下：

| 设置项 | 类型 | 首次启动默认值 |
| --- | --- | --- |
| 语言卡片封面图 | `Bool` | 开启 |
| 页面细网格背景 | `Bool` | 开启 |
| 单词刷点击音效 | `WordQuizSoundEffect` | 关闭 |
| 默认导出文件夹安全书签 | `Data?` | 未设置 |
| 默认导出文件夹展示路径 | `String?` | 未设置 |

开关和音效选择修改后立即生效并保存。音效使用稳定字符串原始值保存；读取到未知值时回退为关闭，避免版本变化造成不可恢复的设置状态。UI 测试和预览使用不写入磁盘的设置实例，不能污染真实用户偏好。

## 3. 默认导出文件夹

### 3.1 沙盒边界

应用启用了 macOS App Sandbox，用户输入一段路径文本并不能自动授予目录访问权限。因此设置页不提供可自由输入的路径框，而是使用系统文件夹选择器，让用户明确授权一个目录。

选择完成后保存 security-scoped bookmark 和只用于展示的路径。真正导出时重新解析书签，并在访问区间内完成文件写入；路径字符串不能作为授权依据。

### 3.2 导出流程

用户在单词本点击“导出模板”时：

1. 生成当天的 Markdown 模板和文件名。
2. 若没有默认文件夹，继续打开原有系统保存面板。
3. 若安全书签无法解析、目录已失效、不是文件夹或没有写入权限，自动回退到系统保存面板。
4. 若默认目录有效，直接写入该目录并显示成功提示。
5. 同名文件已存在时不覆盖，依次使用 `文件名-2.md`、`文件名-3.md`。
6. 已获得目录权限但实际写入失败时显示错误，不谎报成功。

书签变旧但仍可解析时刷新保存；用户可在设置页清除默认目录。

## 4. 设置页面

设置页作为根路由之一，不属于任何语言空间，因此进入设置页会停止当前语言计时。页面包含三个区域：

- **模板导出**：展示当前默认文件夹，提供选择和清除操作。
- **个性化**：提供“语言卡片封面图”和“页面细网格背景”两个开关。
- **答题反馈**：提供“关闭、音效 1、音效 2”三选一控件；选择音效后可以通过扬声器图标试听。

页面保留明确的返回总览入口，并为按钮、开关和路径状态提供稳定的辅助功能标识。最小窗口 `820 × 560` 下不能出现遮挡或横向溢出。

## 5. 首页和个性化效果

### 5.1 首页布局

- 左上继续显示品牌水印和首页标题。
- 个人信息卡片从首页移除，原有用户数据不删除。
- 日历移动到右上角，品牌名称顶部与日历顶部严格对齐。
- 首页顶部增加稳定留白，避免品牌和日历紧贴窗口顶部。
- 语言入口使用独立的固定位置，日历展开或收起不能推动入口移动。
- 语言入口固定为英语在左、日语在右；该顺序只属于首页展示，不改变全局语言枚举和快捷键。
- 设置按钮与主题按钮组成右下角工具组，设置在左、主题在右。

### 5.2 语言卡片封面

两张用户提供的图片作为应用资源打包：

- 英语空间：使用 `picture/English2.png`，打包为 `EnglishCover` 资源。
- 日语空间：`Japanese.jpg`。

图片使用填充裁切，保持卡片尺寸稳定；通过降低饱和度、降低不透明度和叠加主题面板渐变，使其成为文字下层壁纸。卡片标题字号增大，文字始终使用主题高对比色。关闭开关后恢复纯主题面板，不卸载或修改图片资源。

### 5.3 页面细网格

网格由统一 `WorkspaceBackground` 绘制，覆盖总览、设置、语言空间和单词本。网格使用固定间距、半点级细线和低透明度主题边界色，不响应事件、不进入辅助功能树，也不改变任何页面布局。

## 6. 测试与验收

单元测试至少覆盖：

- 两项个性化设置的默认值、修改和重建恢复。
- 答题音效默认关闭、三种选择持久化以及未知存储值安全回退。
- 清除默认目录后不再尝试直接导出。
- 默认目录有效时直接导出，并避免覆盖同名文件。
- 默认目录无效时返回手动保存流程。
- 设置路由具有唯一辅助功能标识。

界面验收至少覆盖：

- 首页不再显示个人信息卡片，日历位于右上角。
- 日历展开前后两个语言入口的位置和尺寸保持不变，最小窗口下互不遮挡。
- 品牌名称与日历顶部对齐，顶部留白在深浅主题下保持一致。
- 设置按钮位于主题按钮左侧并能进入设置页。
- 两个开关立即改变封面和网格，重启后保持。
- 两套主题下封面文字可读，关闭封面后卡片恢复纯色。
- 默认目录有效时模板直接导出；未设置或目录失效时出现系统保存面板。
- `820 × 560` 窗口下设置页、首页工具组和日历均可操作。

## 7. 按页面独立的背景与横格线样式

**修订（2026-09-15）**：2026-09-14 的版本把设置页、语言工作区、单词本、单词刷和集词阁绑在一个「功能页背景」上，
用户关掉一页的网格会连带关掉另一页，这是负反馈；横格线样式也是两页共用，集词阁选「局部隐格」会让单词本一起留白。
自本日起改为按页面各存一份，本节 2026-09-14 的"功能页偏好"结论失效。

背景样式仍用 `PageBackgroundPattern` 的 `none / grid / dots` 三种互斥状态表达。`AppPersonalization` 改为按页面分组：
`dashboardBackgroundPattern`，以及 `wordBook`（`WordBookPersonalization`：排版、横格线样式、背景、台灯光）、
`lexicon`（`LexiconPersonalization`：排版、横格线样式、背景、页眉词、藏书章）、`wordQuiz`（背景）。
视图只读自己那一组；`WorkspaceBackground(page:)` 与横格纸面 `RuledEntrySheet(lineStyle:showsGrid:)`
都由调用页显式传入，纸面本身不读个性化环境值，两页的选择不会互相串。

| 设置项 | 存储键 | 默认值 |
| --- | --- | --- |
| 首页背景（首页与设置页共用） | `settings.dashboardBackgroundPattern` | `grid` |
| 单词本背景 | `settings.background.wordBook` | `grid` |
| 集词阁背景 | `settings.background.lexicon` | `grid` |
| 单词刷背景 | `settings.background.wordQuiz` | `grid` |
| 单词本横格线样式 | `settings.ruledLineStyle.wordBook` | `alignedSolid` |
| 集词阁横格线样式 | `settings.ruledLineStyle.lexicon` | `alignedSolid` |

设置页是根页面，不属于任何功能页，因此与首页共用背景；语言工作区的占位页归集词阁。

迁移规则（旧键只读，任何路径不再写入）：

1. 页键存在就以它为准，未知值回到默认。
2. 功能页背景键缺失时，先读 2026-09-14 中间版本的 `settings.featureBackgroundPattern`；
   再缺失时读 1.0.4 的 `settings.gridBackground`：关闭则该页为「无」，开启则单词本沿用
   `settings.wordBookBackgroundPattern`，其它页为「网格」。
3. 横格线样式页键缺失时读中间版本两页共用的 `settings.ruledLineStyle`；两页都沿用它，直到用户分别改动。

设置页分区顺序：模板导出 → 个性化（主题、封面图、首页背景）→ 单词本 → 集词阁 → 单词刷（背景、答题音效）→ 应用更新，
每个功能页的选项只出现在自己的分区，横格线样式在该页未用横格本时禁用而不隐藏。
辅助功能标识：`settings.background.wordBook / lexicon / wordQuiz`、
`settings.layout.wordBookRuledLineStyle / lexiconRuledLineStyle`；
原 `settings.personalization.featureBackground` 与 `settings.layout.ruledLineStyle` 移除。

单元测试（`VisualPreferencesTests`）覆盖：四页背景各自持久化且改一页不动其它页、中间版本共用键铺开到三个功能页后可各自覆盖、
1.0.4 旧开关迁移、横格线样式按页独立与共用键迁移、未知值回退。
