# 拼写输入稳定性与页面淡入淡出

- 状态：已完成
- 日期：2026-08-22
- 适用范围：单词刷拼写题、根页面路由、语言工作区功能切换

## 1. 背景

当前深度模式进入拼写题后，用户使用英文输入法逐字符键入时会发生输入焦点中断：每输入一个字符，光标便离开输入线，必须再次点击才能继续。现有 UI 测试一次性粘贴完整单词，没有覆盖真实连续打字路径。

同时，首页、设置、语言工作区以及工作区功能之间目前直接替换内容。页面虽然已经声明 `.opacity` transition，但根路由没有提供动画事务，工作区内部功能也没有稳定的转场身份，因此视觉上仍是瞬间切换。

## 2. 目标

- 拼写题在英语直接输入和日语输入法组合文本期间持续保持焦点。
- 每次字符变化可以同步到 SwiftUI 状态，但不能重置原生 field editor、选区或光标。
- 提交答案后才主动结束编辑；自动推进到下一道拼写题时重新获取焦点。
- 首页、设置和语言工作区之间使用克制的淡入淡出。
- 单词本、单词刷和学习资料之间只切换功能内容，顶部悬浮栏和学习时长不参与淡出。
- 转场不改变页面尺寸、位置、计时规则或单词刷离开确认流程。
- 系统开启“减少动态效果”时直接切换。

## 3. 拼写输入修复

拼写输入继续使用 `NSTextField` 适配层，以保留 macOS 原生文本编辑和输入法组合能力。修复遵循以下规则：

1. `controlTextDidChange` 从协调器持有的输入框及其 field editor 读取英文字符，并同步到 SwiftUI `@State`；不能依赖编辑通知对象的具体类型。
2. `updateNSView` 只在属性真正变化时更新 `isEnabled`、`isEditable`、`isSelectable` 和颜色。
3. 原生 field editor 正在编辑时，不使用 `stringValue` 回写相同文本，避免重置选区或结束编辑。
4. SwiftUI 请求聚焦时，只在文本框尚未拥有 field editor 时调用 `makeFirstResponder`。
5. 只有提交、题目离开或控件被禁用时才主动结束编辑。
6. 焦点请求必须核对当前 `NSTextField` 仍在窗口中，防止异步任务聚焦已被替换的题目。
7. 拼写输入关闭系统自动纠错、文本替换与自动补全，答案只反映用户实际键入的内容。

## 4. 页面转场层级

转场分成两个层级，不能用一次全局动画同时处理。

### 4.1 根页面

根页面身份只包含：

```text
首页
设置
某个语言工作区
```

工作区内部从单词本切换到单词刷时，根页面身份保持不变。因此 `ContentView` 不会让整个 `WorkspaceShell` 连同顶部栏一起淡出。

### 4.2 工作区功能内容

`WorkspaceShell` 使用 `WorkspaceFeature` 作为内容身份，只对其承载的功能页面执行透明度转场。悬浮功能栏、学习时长、顶部感应区和离开协调器保持在稳定外壳中。

## 5. 动画规范

- 转场属性：仅 `opacity`。
- 动画曲线：`easeInOut`。
- 建议时长：约 `0.22` 秒。
- 不使用横向或纵向位移，避免产生方向暗示和控件跳动。
- 不通过条件 padding、frame 或 safe-area 改变页面几何。
- “减少动态效果”开启时使用 `.identity` 且不创建动画事务。

## 6. 状态与生命周期约束

- 路由值仍是页面状态的唯一来源，动画不维护第二套路由。
- 路由变化时立即同步计时归属；淡出的旧页面不能延长学习时间。
- 离开单词刷的确认在路由变化前完成；取消后不启动转场。
- 自动推进任务在拼写反馈期间继续按原规则运行。
- 工作区功能交叉淡出期间，新旧页面可能短暂共存，因此离开拦截器按 UUID 安装和移除，旧页面不得移除新页面的拦截器。

## 7. 测试与验收

### 拼写输入

- UI 测试使用真实键盘事件连续输入 `language`、`time`、`book`，并在首题中不重新点击输入框分两段键入；两段输入后必须持续持有焦点，提交后必须判定正确。
- 输入期间无需再次点击文本框。
- 提交后输入框位置不变化，反馈结束后自动推进。
- 下一道拼写题自动获得焦点并可继续逐字符输入。

### 页面转场

- 单元测试验证根转场身份忽略同语言功能变化，但区分首页、设置和不同语言工作区。
- UI 测试验证转场结束后目标页面存在、来源页面消失。
- 工作区内部切换时，顶部栏保持可见且 frame 不变化。
- 页面核心控件转场前后最终 frame 与原布局一致。
- 开启“减少动态效果”时导航功能仍完整。

## 8. 非目标

- 不新增滑动、缩放、模糊或 3D 页面动画。
- 不改变主题波纹、品牌文字和答题反馈动画。
- 不持久化页面转场状态。
- 不修改单词刷抽题、判题、计分或自动推进时长。

## 9. 实施验证

- Debug 构建通过。
- 69 项单元测试全部通过，包含根页面转场身份测试。
- macOS UI 自动化已验证英文首题分两段连续键入时不需要重新点击输入框，焦点保持在拼写框，并能提交进入反馈状态。
- 最后新增的反馈无障碍标签已通过编译；由于系统安全审查临时拒绝再次启动 UI 自动化，本轮未重跑该标签的最终断言，需在下一次 UI 验收中补跑。
