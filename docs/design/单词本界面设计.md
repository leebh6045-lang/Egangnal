# 单词本浏览与编辑界面

## 阶段范围

本阶段把已经完成的单词本数据基础接入语言空间，完成可用的浏览、模板导出、Markdown 导入和显式编辑闭环。学习计时、普通资料阅读和单词卡片式记忆功能不在本阶段实现。

沉浸式阅读的后续优化规则见：[单词本沉浸式阅读](单词本沉浸式阅读.md)。

## 页面结构

单词本作为语言空间下的独立页面存在，页面路由携带不可变的 `LanguageSpace`。进入页面时只读取该空间的词条，返回时回到对应语言空间；日语和英语不共享页面状态。

页面自上而下分为：

1. 返回按钮、当前语言标题和操作按钮。
2. 浏览模式分段控制：默认分页、按日期。
3. 当前模式的词条内容区域。
4. 页码或日期导航。

右上角提供模板导出和 Markdown 导入。导入文件选择器打开时捕获当前语言空间，文件解析和写入始终使用这个空间，即使用户之后触发其他导航也不改变归属。

## 默认分页模式

- 查询主词条并按仓储稳定顺序展示，每页最多 20 条。
- 提供上一页、下一页和当前页/总页数；0 条时不显示无意义的页码。
- 每条显示单词和中文意思；`isHighFrequency` 为真时单词使用蓝色强调色。
- 该模式没有编辑、删除和新增入口，避免浏览时误改数据。

## 日期模式

- 以词条出现日期去重后按日期倒序生成日期页。
- 每次只显示一个文档日期的全部词条，内容区域使用滚动容器，不限制当天条目数量。
- 提供上一日、下一日和当前日期标题；没有日期记录时显示空状态。
- 手动新增的无日期词条独立显示在“未归档单词”分组，不伪造当天日期，也不参与高频判断。
- 日期模式仍然是浏览模式，编辑能力必须通过显式编辑开关开启。

## 显式编辑模式

- 默认分页模式始终只读，不显示编辑入口；切换到按日期模式后，页面操作区的编辑按钮才可切换“浏览/编辑”状态。
- 编辑状态显示新增按钮；每条显示编辑和删除图标。
- 新增和修改使用同一个表单，单词和中文意思均不能为空；提交失败保留草稿并显示错误。
- 删除需要确认，成功后刷新当前页面；取消不会改变数据。
- 编辑主词条不会改变它的历史出现日期；删除主词条由仓储同步清理出现记录和空批次。
- 切换浏览模式或离开页面不自动保存草稿。

## 导入与导出

- 导出按钮只创建当天的空白 Markdown 模板，文件名包含当前日期，不读取词条列表。
- 导入只接受 Markdown 文件。读取安全范围内的文件数据后先解析，再调用仓储一次性提交。
- 导入成功显示新增词条和跳过重复记录的结果；同日重复导入不会制造第二条日期记录。
- 取消选择不显示错误，也不修改数据；解析、读取或持久化失败显示可理解的错误信息。
- 持久化降级为不可用状态时，仓储拒绝写入，页面显示错误而不伪造成功状态。

## 辅助功能与稳定性

- 页面、模式切换、导入、导出、编辑、新增、删除和分页按钮使用稳定的 accessibility identifier。
- 单词列表行使用组合辅助功能元素，读取顺序为单词、中文意思和高频状态。
- 列表和滚动区域使用固定最小高度，错误信息出现或消失不应推动顶部操作区跳动。
- 主题切换仍由全局首页按钮控制，单词本页面只读取当前语义调色板，不复制主题状态。

## 验收标准

- 从日语、英语语言空间均可进入各自单词本，返回路径正确且数据不串空间。
- 默认模式覆盖 0、1、20、21、40、41 条分页边界，且没有修改入口。
- 日期模式日期严格倒序，一页只显示一天并可滚动；手动词条独立显示。
- 导出模板不包含已有词条；导入后词条、重复规则和日期记录与数据基础阶段一致。
- 显式编辑的新增、修改和删除可持久化，删除后无孤立出现记录或空批次。
- 导入取消、格式错误和存储错误不会留下部分数据。
- 现有主题、首页导航和窗口布局测试继续通过。
