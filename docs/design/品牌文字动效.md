# 品牌文字动效

## 目标

首页品牌文字默认显示 `Egangnal`。点击后，八个字母以稳定身份逆序重排为 `Language`，其中中间的 `n` 独立旋转并过渡为 `u`；重排完成后，`For` 和 `Study` 从两侧淡入，形成 `For Language Study`。再次点击主文字时，附加词先淡出，字母再反向重排回 `Egangnal`。

## 字母映射

重复字符不能直接使用字符值作为动画身份，必须使用稳定的源索引：

```text
源顺序: 0:E 1:g 2:a 3:n 4:g 5:n 6:a 7:l
目标顺序: 7:L 6:a 5:n 4:g 3:u 2:a 1:g 0:e
```

这表示整体逆序，源索引 `3` 的 `n` 负责独立的 `n -> u` 变化，索引 `0` 和 `7` 同时完成大小写变化。

## 动效约束

- 品牌画布预留完整 `For Language Study` 的宽高，动效不能改变首页行高或推动其他控件。
- 八个字母使用固定槽位和稳定 ID，只改变位置、旋转、透明度和字形内容。
- 重排沿短弧线进行，并为字母增加轻微错峰，避免八个字母完全同步穿越。
- `For`、`Study` 只在 `Language` 稳定后淡入；收起时先淡出，再反向重排。
- 动画期间锁定品牌按钮和主题按钮，防止两个快照型动效互相捕获。
- 开启“减少动态效果”时直接呈现目标状态，不执行飞行和旋转。

## 交互与辅助功能

- 品牌区域使用稳定标识 `dashboard.brand.toggle`。
- 内部字母对辅助技术隐藏，只暴露一个聚合按钮。
- 折叠态标签为“Egangnal，展开品牌含义”，展开态标签为“Language，收起品牌含义”。
- 展开态辅助功能值为 `For Language Study`，折叠态值为 `Egangnal`。
- 动画过程中使用“正在展开”或“正在收起”，避免辅助功能提前报告最终状态。

## 验收标准

- 点击 `Egangnal` 后最终准确显示 `For Language Study`，再次点击后恢复 `Egangnal`。
- 中间态能观察到字母逆序移动，`n -> u` 有独立旋转变化，附加词不会提前出现。
- 品牌动效前后，首页标题、语言入口、个人信息、日期面板和主题按钮的 frame 不发生变化。
- 快速重复点击不会打断状态机或留下附加词。
- 单元测试覆盖映射唯一性、目标字符串和正反向对称性；UI 测试覆盖展开、收起和主题按钮可用性。

## 实施结果

状态：已完成

- 使用固定 `400 × 60` 品牌画布，八个字母按源索引保持稳定身份。
- 字母沿短弧线错峰重排，源索引 `3` 的 `n` 独立旋转并变为 `u`。
- 展开时先重排再淡入陪衬词；收起时先淡出陪衬词再反向重排。
- 品牌与主题动效双向互斥，减少动态效果时直接切换最终状态。
- 2026-08-04 构建通过；17 项单元测试和 9 项 UI 测试通过，并完成真实窗口截图验收。
