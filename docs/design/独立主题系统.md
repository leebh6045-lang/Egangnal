# Egangnal 独立主题系统

- 状态：已完成
- 日期：2026-08-04

## 目标

Egangnal 不再跟随 macOS 的系统外观变化，而是维护自己的浅色和深色主题。主题切换由用户在首页主动控制并本地保存。

本阶段同时消除标题栏与内容区之间的分界线，让应用背景延伸到窗口顶部，形成完整、连续的学习空间。

## 主题模式

首版只提供两个模式：

- 浅色：保持简洁、低干扰和清晰层级。
- 深色：使用深炭色背景、清晰的不透明面板和更饱和的功能强调色。

不提供“跟随系统”模式。首次启动默认使用深色主题，之后恢复用户最后一次选择。

UI 自动化测试使用独立的内存主题状态，不读取或覆盖真实用户偏好。

## 视觉规则

所有页面通过统一语义颜色访问主题，不在业务视图中散落背景色和文字色：

- `canvasTop`、`canvasBottom`：窗口连续背景。
- `panel`、`panelRaised`：普通面板和悬停、控件层级。
- `border`：面板边界。
- `primaryText`、`secondaryText`、`tertiaryText`：文字层级。
- `japaneseAccent`、`englishAccent`：语言空间强调色；两者统一使用同一套浅蓝色，覆盖首页悬停、学习空间、单词本和单词刷。
- `grammarAccent`：语法区域强调色。
- `calendarAccent`：当前日期和主题按钮强调色。
- `ambientLeading`、`ambientTrailing`：深色背景两侧的低透明度环境光；浅色主题为透明。

深色主题不使用系统模糊材质作为主要面板背景。面板使用明确的不透明颜色和一像素边框，避免灰雾感；饱和色只用于图标、当前日期、悬停和关键状态，不大面积铺满背景。

浅色主题保持接近现有视觉，但同样改用自有颜色，确保系统切换外观时应用内容不发生变化。

## 窗口与标题栏

- 隐藏窗口标题文字。
- 标题栏背景透明并使用全尺寸内容视图。
- 移除标题栏底部分隔线。
- 红黄绿窗口按钮保留，窗口空白区域仍可拖动。
- 启动时为 `NSWindow` 设置与初始主题匹配的原生控件外观；运行中页面与透明标题栏背景统一由 SwiftUI 主题驱动。
- `NSWindow` 的透明标题栏和全尺寸内容结构只在窗口挂载时配置；运行中切换主题不得再次触发标题栏布局计算。

## 交互与持久化

- 主题按钮位于首页右下角。
- 按钮使用太阳或月亮图标表达将要切换到的主题，并提供工具提示和辅助功能标签。
- 点击后目标主题先应用到底层，不需要重新启动；旧主题快照会暂时覆盖在上方。
- 旧快照由按钮中心向外扩展的圆形软边渐变逐步退场，切换过程中页面内外会短暂同时呈现新旧主题；减少动态效果或快照失败时直接切换。
- 标题栏背景由全尺寸内容视图承载，必须随同一波纹变化，不单独提前切换原生窗口外观。
- 选择通过本地偏好保存，不接入 SwiftData、云端或账号系统。

## 验收标准

- macOS 系统外观变化不会改变 Egangnal 当前主题。
- 浅色和深色主题的窗口背景、面板、文字、语言强调色均来自应用调色板。
- 深色面板不再使用系统模糊材质，边界和文字清晰可辨。
- 标题栏和首页之间没有可见分隔线，背景连续覆盖窗口顶部。
- 首页右下角主题按钮在 `820 × 560` 内容区下可见、可点击。
- 切换主题后总览、日语空间和英语空间同时更新。
- 重启应用后恢复上一次主题选择。
- 单元测试覆盖主题切换和持久化，UI 测试覆盖两套主题启动和按钮切换。
