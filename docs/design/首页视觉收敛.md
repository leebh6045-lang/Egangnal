# Egangnal 首页视觉收敛

- 状态：已完成
- 日期：2026-08-04

## 目标

本阶段只收敛首页的布局比例、深色背景氛围和主题切换反馈，不扩展学习计时、资料管理或其他业务能力。

首页继续保持简约：入口只承担进入日语、英语空间的职责，累计学习时长仅在对应语言空间内部展示。

## 布局规则

首页使用左右两列、上下两行的明确结构：

- 第一行左侧为品牌水印和入口标题，右侧为个人信息。
- 品牌水印列相对原基线向上抬高 42 点，保留与窗口控制区之间的安全距离。
- 第二行左侧为两个语言入口，右侧为日期或展开后的挂历。
- 第二行左右内容共享同一顶部基线，语言入口上边缘必须与日期面板上边缘平齐。
- 语言入口采用两张独立卡片，不再使用横向长条比例。
- 品牌水印及副标题与下方语言入口卡片共享左侧基线。
- 卡片只保留中文名和原文名，不显示装饰图标、进入箭头或累计学习时长。

默认窗口与 `820 × 560` 最小内容区都必须保持入口可操作，展开挂历不能遮挡主题按钮。

## 深色环境光

深色背景在原有清晰实色渐变上增加两层低透明度、大范围边缘环境光：

- 日语红从一侧轻微进入背景。
- 英语蓝从另一侧轻微进入背景。
- 环境光不得形成清晰的独立圆球，也不得使用模糊材质影响面板清晰度。
- 环境光只增强空间层次，不承担信息表达，不降低文字和面板边界对比度。
- 浅色主题保持克制，对应环境光颜色为透明。

## 主题波纹

点击首页右下角主题按钮后，新主题从按钮中心以圆形波纹向窗口最远角扩展：

1. 切换前捕获当前窗口内容快照。
2. 将目标主题应用到底层，但在动画开始时仍由旧主题快照覆盖整个窗口。
3. 旧快照使用以按钮中心为起点的透明圆形软边遮罩；圆心先露出新主题，渐变边缘再逐步向外扩展。
4. 圆形软边覆盖窗口最远角后移除快照，避免清理时出现闪回。

标题栏背景必须和内容区处于同一波纹覆盖范围。主题切换期间不得重新配置窗口结构、改变内容区高度，或让标题栏先于页面独立换色；语言入口、个人信息和日期面板的屏幕位置在动画前后必须保持稳定。

动画期间禁止重复触发，避免主题状态和覆盖层错位。系统开启“减少动态效果”或窗口快照失败时直接切换主题，保证功能可用性优先于动画。

## 可维护性约束

- 布局尺寸集中在首页视图或主题常量中，避免散落的补偿偏移。
- 波纹快照、几何计算和覆盖层独立封装，不将 AppKit 细节放进入口按钮。
- 新代码只在非直观逻辑处添加简洁中文注释。
- 自动化测试使用稳定的辅助功能标识和几何断言，不依赖截图人工判断全部行为。

## 验收标准

- 日语入口、英语入口和日期面板的上边缘误差不超过 2 点。
- 两个语言入口是独立卡片，宽高比明显小于原横向长条入口。
- 首页不存在 `0.0 小时` 或其他累计时长展示，语言空间内部仍显示对应时长。
- 深色背景可见轻微红、蓝环境光，面板仍为清晰不透明实色。
- 主题从右下按钮位置以连续、带柔和渐变边缘的圆形波纹完成切换；动画中间态应同时存在新旧主题区域，动画期间不能重复触发。
- 波纹经过标题栏时才改变对应区域，主题切换前后首页主要控件不得产生统一的纵向位移。
- 开启“减少动态效果”或快照失败时仍能直接、正确切换主题。
- 构建、单元测试和核心 UI 测试通过。
