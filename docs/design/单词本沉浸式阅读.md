# 单词本沉浸式阅读

## 目标

本次优化只改变单词本的阅读呈现和记忆辅助交互，不改变 SwiftData 模型、Markdown 协议、导入规则或编辑权限。

## 阅读布局

- 单词和中文释义使用同一横向行展示，正文统一使用 `30pt` 大字号。
- 词条区不使用面板背景、边框或逐条分隔线，使用自适应网格直接铺在页面背景上。
- 默认窗口和 `820 × 560` 最小窗口均固定显示两列词条；两列和词条内部的单词、释义均等比例伸缩。
- 每行两个词条的单词和释义分别占据四等分区域，文字在各自区域内居中，形成横向均衡的阅读视线。
- 长单词或长释义允许在自己的半列内换行，不挤占相邻词条。
- 隐藏文字时使用与原文字占位一致的圆角矩形遮盖，避免其他词条跳动。

## 标题与引导

- 标题只显示当前语言名称和“单词本”，不添加装饰性书本图标。
- 标题右侧使用语言空间强调色显示圆圈问号按钮。
- 点击问号后从按钮右侧展开气泡，显示两行固定引导：先导出模板并记录生词，再导入单词本；点击单词或词义可辅助记忆。
- 浅色主题的引导气泡使用浅黄底色和黑色文字，保证内容与背景有明确对比度。

## 工具栏

- 默认收起导入、导出、浏览方式和编辑等功能按钮。
- 顶部保留返回入口、单词本标题和下拉手柄；点击手柄后功能区向下展开，再次点击时向上收起。
- 收起功能栏会同步退出编辑模式，避免隐藏编辑入口后仍残留编辑状态。
- 页面容器不设置会向子视图继承的辅助功能标识，标题、工具栏和阅读按钮保留各自独立标识。
- 默认分页依旧只读；编辑按钮只有在按日期模式下展开工具栏后显示。

## 记忆辅助

- 点击任意单词或释义只切换当前词条对应字段的显示状态，不写入持久化数据。
- 隐藏状态使用带轻微描边的圆角矩形完整覆盖文字；再次点击同一位置恢复文字。
- 刷新按钮清除当前页面所有逐条隐藏状态，并恢复正常显示模式。
- 眼睛按钮始终显示斜线眼睛图标，其循环状态不通过更换图标表达。
- 眼睛按钮循环切换：正常显示 -> 隐藏全部单词 -> 隐藏全部释义 -> 隐藏全部单词。
- 刷新和眼睛按钮纵向悬浮在右下角，滚动内容为其预留底部空间，分页导航为其预留右侧空间。
- 全局隐藏模式下点击单个字段可以临时显示该字段；刷新后清除这些临时显示状态。
- 翻页、日期切换、浏览模式切换和重新加载数据时清除记忆辅助状态，避免旧页面状态影响新页面。

## 验收标准

- 默认和日期模式的词条均以 `30pt` 字号横向显示，每行恰好两个词条，词条区没有卡片外框。
- 标题左侧没有装饰图标；问号气泡从按钮右侧展开并严格显示两行引导文字。
- 浅色主题下气泡为浅黄底色、黑色文字；每行两个词条的四个文字字段在页面中均匀居中。
- 工具栏初始收起，点击下拉手柄后可以看到所有原有功能按钮并正常操作。
- 单独点击单词或释义会切换对应圆角遮盖，页面布局不发生跳动。
- 刷新恢复所有字段；眼睛按钮可以在隐藏单词和隐藏释义之间循环切换。
- 日语、英语空间、默认分页、日期分页和显式编辑规则保持原有行为。
