## 2. 主题

### 2.1 三套主题与切换

`AppAppearance` 由两态改为三态：`light`（浅色）、`warm`（暖纸）、`dark`（石墨）。

- 首页右下角按钮按 **浅色 → 暖纸 → 石墨 → 浅色** 循环（`AppearanceStore.cycle()`）；图标表达"将要切换到"的主题：太阳 / 合上的书 / 月亮。
- 设置页「个性化」新增三选一「主题」（`AppearanceStore.select(_:)`），作为非顺序入口。
- 暖纸的 `colorScheme` 为 `.light`，系统控件按浅色渲染；窗口 `NSAppearance` 按 `colorScheme` 取 aqua / darkAqua，不再直接比较枚举值。
- 旧偏好值 `light` / `dark` 无需迁移，`dark` 直接呈现为石墨。
- 波纹切换动画不受影响：它只是"截图后切换"，对任意两态都成立。

### 2.2 色板

数值以 `AppTheme.swift` 中的 `AppPalette` 为准，这里只记录设计意图：

- **暖纸**：底色向米色偏移（#F5F1E9 → #EBE5D9），面板 #FCFAF5，文字用暖黑 #221F1A，强调色降一档饱和度（#3A64B4）避免在暖底上发紫，收藏色用深金。
- **石墨**：中性深灰（#0E0F11 → #15171A），面板 #1B1E22，边框 #5A6068；`ambientLeading` / `ambientTrailing` 均为透明。层次只靠面板与边框的明度差表达。
- 新增两个语义色：`ruledLine`（横格线）与 `ruledMargin`（页边线）。三套主题各自选择与背景网格**不同色相**的横线：浅色墨蓝 42%、暖纸赭色 46%、石墨冷灰 30%。

## 3. 顶部功能栏材质

> **2026-09-16 修订（用户视觉复核后）**：本节原定"192 pt 通栏渐变材质带"。实测后用户认为
> 玻璃面积太大、质感不够，期望的是 Launchpad 那种**小面积、高模糊**的玻璃，
> 并且功能栏要像 macOS 程序坞一样"光标走了就收"。下面按修订后的结论重写，原参数仅作历史记录。

### 3.1 定稿参数（2026-09-16）

| 项目 | 值 |
| --- | --- |
| 形状 | 贴合功能栏的一块连续圆角板，**只比胶囊外扩 8 pt（水平）/ 6 pt（垂直）**，圆角取板高的一半 |
| 材质 | SwiftUI `.thickMaterial`（厚材质 = 模糊更重，这是"玻璃感"的主要来源） |
| 着色 | 面板色 **0.12**（`workspaceNavigationGlassTint`）。着色越淡，透出的模糊内容越多 |
| 高光 | 顶缘 1 pt 描边 + 自上而下到中点的薄光渐变，均为 0.12（`workspaceNavigationGlassSheen`） |
| 胶囊 | 自身**不再画材质**，只在「减少透明度」时提供不透明底面；玻璃质感全部由背后的板承担 |
| 学习时长 | 留在玻璃板**之外**，不参与这块玻璃（板只包功能栏） |
| 动效 | 玻璃板与功能栏同进同出，只淡入淡出，不随功能栏位移 |

**为什么把材质从胶囊移到板上**：原先胶囊自己画 `.thinMaterial` + 0.38 着色，外层还有一条通栏材质带，
同一块区域叠了两层材质加两层着色——既糊得太大，又因为叠色而显得像实板。现在玻璃只有一层，面积也小。

### 3.2 显隐节奏（2026-09-16 修订）

- 指针离开功能栏、学习时长与顶部感应区后，**200 ms** 内收起
  （`workspaceNavigationHideDelay`；原为 650 ms，用户认为"过度久留遮挡功能页面"）。
- 参考 macOS 程序坞的退场节奏；指针重新进入任一区域会取消待执行的隐藏。
- 顶部感应区高度保持 24 pt：既容易唤起，又不至于让页面顶部的操作误触发。
- 功能栏**不再随进入语言空间自动唤出**（详见《语言工作区功能导航重构设计》第 3 节第 6 条修订）。

### 3.3 边界

- 材质跟随 SwiftUI 的 `colorScheme` 环境值，根视图已按应用主题设置，不读系统外观。
- 开启「减少透明度」时材质层不渲染，玻璃板与胶囊都退回不透明面板。
- 玻璃板是覆盖层，页面布局不为它让位（沿用功能栏既有约束）。
- **系统材质的模糊半径固定**，无法像预览稿那样精确调到 4 pt；观感由材质厚度、着色浓度与板面积共同决定。
- 系统开启「减少动态效果」时不播启动页，功能栏本身仍可正常唤出。

## 5. 横格本

### 5.1 用户可见行为

- 设置页新增「词条排版」区：**单词本**（默认 / 横格本）、**词库**（默认 / 横格本）、**横格线样式**（对齐实线 / 虚线 / 局部隐格）。
- 两页的排版**互相独立**；横格线样式两页共用，两页都不用横格本时该选项禁用而不隐藏。
  （**修订** 2026-09-15：横格线样式也改为按页各存一份，每页的样式在该页未用横格本时禁用；见第 12 节。）
- 横格本下：每行两个词条，行高 56 pt，左侧行号列 56 pt 与一条淡红页边线，两个词条格之间一条竖线，每行底部一条横线；文字靠左、单词与词义首行基线对齐、词义单行截断。
- 遮盖、高频词标记、收藏按钮、编辑与删除、翻页与滚动在两种排版下行为一致。

### 5.2 与背景网格的关系

背景网格是 28 pt 间距、0.5 pt、边框色 13% 的实线。横格本用"一张放在桌上的纸"来处理冲突：

1. `WorkspaceBackground` 在纸面所在的**滚动区**内抠掉背景网格（`gridCutout`）。登记的是滚动区而不是纸面本身：纸面比视口高，滚动后会伸到页眉底下。
2. **对齐实线** 与 **虚线**：纸面自己重画一套网格，随行一起滚动，因此横线在任意滚动位置都落在网格线上；竖线相位按全局坐标计算，与窗口背景网格同相。区别只在横线是实线还是 7 / 5 短划。
3. **局部隐格**：纸面留白，只画横线、页边线与分隔竖线；抠除区域上下各 20 pt 淡出（`ruledGridFeather`），避免生硬断口。
4. 关闭「页面细网格背景」时，纸面也不画网格。

几何不变量（有单元测试锁定）：行高、行号列宽、纸面尾部空白都是网格间距的整数倍；分隔竖线吸附到最近的网格线，极窄窗口下第一个格子至少保留一格。

### 5.3 代码结构

| 文件 | 职责 |
| --- | --- |
| `Domain/AppPersonalization.swift` | `WordBookLayoutStyle`、`LexiconLayoutStyle`、`RuledLineStyle` 三个枚举与个性化值 |
| `Design/EntryFieldArrangement.swift` | 排版样式 → 字段排布形态（对齐、宽度比、基线、行数、最小高度）的唯一映射 |
| `Design/EntryFieldsLayout.swift` | 原 `EqualFieldsLayout` 的推广：按比例分配宽度、可选首行基线对齐 |
| `Design/RuledEntrySheet.swift` | 纸面：行、行号、页边线、横线、纸面网格、区域登记；几何规则集中在 `RuledSheetGeometry` |
| `Design/AppTheme.swift` | `ruled*` 常量、`ruledLine` / `ruledMargin` 语义色、背景网格抠除 |
| `Features/WordBook/*`、`Features/LearningMaterials/*` | 只做两件事：按排版样式选择容器（`LazyVGrid` 或 `RuledEntrySheet`）；把 `fieldArrangement` 交给词条视图 |

**扩展规则**（为后续"分别给某一页加新排列方式"准备）：

1. 只给某一页加样式时，只改该页的枚举（`WordBookLayoutStyle` 或 `LexiconLayoutStyle`），另一页不受影响。
2. 新样式先在 `EntryFieldArrangement` 里回答"字段怎么排"；若现有两种形态够用就复用，不够再加一个 case。
3. 新样式的容器放在 `Design/`（两页可能共用）或该页的 Feature 目录（只此一页用）；页面视图里只增加一个 `switch` 分支。
4. 词条视图（`WordBookEntryRow`、`LexiconEntryCell`）**不判断排版样式**，只读 `EntryFieldArrangement`。

## 8. 验收标准

1. 首页按钮三态循环；设置页三选一；重启后保持；`dark` 旧值呈现为石墨且无环境光。
2. 功能栏唤出时顶部出现渐进材质带，页面布局不变；减少透明度时退化为着色。
3. 单词本与词库的单词、词义字号一致，切换页面时文字尺寸不跳变。
4. 两页可分别选择横格本；横格线三种样式可切换；关闭网格背景时纸面无网格。
5. 「对齐实线」下任意滚动位置横线都落在网格线上；「局部隐格」下纸面区域无背景网格且上下边缘平滑。
6. `820 × 560` 与三套主题下，设置页新增控件不溢出，横格本第一个词条格至少一格宽。
7. 单元测试与受影响的界面测试通过。

### 10.2 手帐

- 排版：按"最近一次出现日期"分组，日期由近到远，无日期的词条归入末尾"未归档"组；组内保持传入顺序（默认分页下即洗牌顺序）。按日期浏览时页面标题已是这一天，手帐不再重复分组标题。
- 每组：一个语言强调色圆点 + 日期标题 + 词数（当天标"今天"）；每条前一个项目符号；两栏靠左；行高 46 pt。
- 字体：圆体（`Font.Design.rounded`）。这是手帐样式自带的气质，默认与横格本的字体不变。
- 高频词：不再染色，改为一笔略斜的荧光笔色带（`markerHighlight`）压在单词下半部。
- 分组规则在 `Domain/WordBookPresentation.swift` 的 `WordBookJournal` 中，有单元测试；容器是 `Design/JournalEntrySheet.swift`；字段排布形态新增 `EntryFieldArrangement.journal`。
