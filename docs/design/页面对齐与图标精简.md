# 页面基线与图标收敛

- 状态：已完成
- 日期：2026-08-16

## 目标

本阶段只统一首页、学习空间和单词本的视觉基线，并移除不承载操作含义的装饰图标；不改变页面路由、学习时长、单词本数据或现有交互。

## 对齐规则

- 页面主要内容统一以 `AppTheme.contentPadding` 作为左侧基线，不再对局部标题额外增加固定缩进。
- 首页品牌水印及其副标题与下方语言入口卡片左边缘对齐。
- 学习空间的“返回总览”、空间标题、学习时长和功能卡片共享同一左边缘。
- 单词本返回箭头的可见图形与“全部单词”或日期标题左边缘对齐，同时保留稳定的点击区域。

## 图标规则

- 移除首页语言入口中的语言图标与进入箭头。
- 移除学习空间标题前的语言图标，以及“学习资料”“单词本”卡片标题前的装饰图标。
- 返回、帮助、主题、编辑、翻页和记忆辅助等承担明确操作含义的图标继续保留。
- 学习时长的时钟和空状态提示仍承担信息识别作用，本阶段不调整。

## 验收标准

- 首页品牌水印及副标题与第一张语言入口卡片的左边缘误差不超过 2 点。
- 学习空间返回按钮、空间标题与第一张功能卡片的左边缘误差不超过 2 点。
- 单词本返回箭头的可见起点与内容标题共享左侧基线。
- 截图中指出的语言标识、空间标题标识和卡片标题标识不再显示。
- 两套主题、日语与英语空间、紧凑窗口下均不出现布局溢出，现有交互测试继续通过。
