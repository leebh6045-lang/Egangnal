# Egangnal 1.0.4

这是一次大版本更新，新增内置词库与单词刷联动。

## 新增词库

- 内置 7,116 条分级英语词条：全部 / 六级 / 四级 / 高中 / 初中。
- 支持英文前缀与中文释义检索；点击可遮盖单词或词义，用于自我测试。
- 悬停词块可看音标、完整释义、等级与收藏日期。
- 每次进入自动换一批，也可手动「换一批」。

## 把生词收进单词本

- 悬停词块后点 ⊕ 即可收藏，已收藏的词显示为浅黄色；再点一次取消收藏。
- 收藏会计入**当天**，所以它会出现在单词本的日期分组里。
- 取消收藏只移除词库收藏的记录，文档导入的词条与日期绝不受影响。

## 单词刷可以直接考词库

- 测试范围新增「词库」：选一个等级（或全部），干扰项从整个词库抽取。
- 考词库时选项会带词性（如 `n. 苹果, 家伙…`），与词库、单词本里显示的形态一致。
- 收藏的词本来就会进入默认抽题范围，这次用测试锁定并修复了一个缺陷：
  同一题内不再出现两个看起来完全一样的选项。
